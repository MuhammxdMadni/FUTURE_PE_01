# Task 1 – AI-Powered YouTube Script & Thumbnail Generator

## Internship
Future Interns – Prompt Engineering Track

## Task Overview
In this task, I created an AI-powered YouTube content package using prompt engineering and AI tools. The goal was to generate an engaging YouTube video idea, script, thumbnail, and final video suitable for students and beginners.

## What I Created
- YouTube video title and content idea
- Full YouTube script (1000+ words)
- Thumbnail text and design
- AI-generated and edited video
- Prompt chain documentation

## Tools Used
- ChatGPT – Script and idea generation
- Canva – Thumbnail design
- Pictory / InVideo – Video creation
- GitHub – Project documentation

## Folder Structure
- Prompt_Documentation: AI prompt chains used
- Script: Final YouTube script
- Thumbnail: Designed thumbnail image
- Video: Final video or video link
- Screenshots: Supporting visuals

## Learning Outcome
This task helped me understand how prompt engineering can be used to create complete content pipelines, from ideation to final delivery, using AI tools efficiently.
